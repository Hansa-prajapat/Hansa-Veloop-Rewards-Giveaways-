# Veloop Rewards & Giveaways

Premium dark-themed React + Vite frontend inspired by the requested Veloop dashboard design.

## Features
- Responsive dark neon dashboard
- Watch & Earn section with 6 ad cards
- 30-second ad timer and coin reward
- Balance and daily progress updates
- Recent activity feed
- Sidebar navigation
- Premium gradients, cards and micro-interactions
- No backend or API keys required for the demo

## Run locally
```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Deploy on Vercel
Framework Preset: Vite
Build Command: `npm run build`
Output Directory: `dist`
Install Command: `npm install`
Root Directory: `.`

## GitHub
Create a repository, upload all project files except `node_modules`, then connect that repository to Vercel.
